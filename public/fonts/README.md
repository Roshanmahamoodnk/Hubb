# HUBB web fonts

The bundled Noto Kufi Arabic and Space Grotesk subsets are distributed under the SIL Open Font License 1.1. They are self-hosted so the storefront does not wait on a third-party font stylesheet during first paint.

- Noto Kufi Arabic: https://fonts.google.com/noto/specimen/Noto+Kufi+Arabic
- Space Grotesk: https://fonts.google.com/specimen/Space+Grotesk
