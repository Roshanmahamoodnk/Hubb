# HUBB award-caliber research memory

Updated: 2026-08-18

## Diagnosis

HUBB already owns the hard part: a recognizable bilingual name, seven collectible packages, strong Arabic display composition, sensory flavor data, and a culturally specific crack ritual. The credibility break was cinematic media: a synthetic 15-second pack montage was asked to carry the emotional weight of real product film. On small viewports the page served a 540×960 source, and the homepage repeated the same film in the hero and later cinema stage. Repetition reduced surprise; resolution and synthetic movement reduced realism.

The V8 decision is to make the approved high-resolution packs the homepage signature interaction and move the existing films into an explicitly labeled archive. A future production shoot replaces the archive rather than blocking the current experience.

## Named art direction

**Saudi Night Market Cinema**

- Emotional word: magnetic.
- Physical sensations: foil catching street light, a shell snapping, seasoning dust, a cold bag passed hand-to-hand, colored shop signs after dark.
- Metaphor: seven illuminated product worlds on one night-market stage.
- Non-web references: contemporary Riyadh night signage, contact sheets from product photography, Sadu rhythm treated as structure rather than ornament.
- Axes: contemporary; assured; editorial; tactile/precise; grid-with-violations; dark-room with flavor color.
- Motion: crisp editorial reveal, cubic-bezier(.16,1,.3,1), 0.45–0.75s; auto sequence 2.4s; no bounce.

## What winning work repeatedly does

The strongest pattern is not “more animation.” It is coherence: an owned metaphor governs typography, composition, motion, and interaction. Awwwards evaluates design, usability, creativity, and content separately, so spectacular motion cannot rescue poor navigation or weak content. Current packaging awards similarly reward intentional brand systems, shelf distinction, material innovation, and cultural relevance rather than surface decoration.

## Repository intelligence

Use repositories for infrastructure, never for a recognizable finished look.

| Repository | Why teams use it | HUBB decision |
|---|---|---|
| [darkroomengineering/lenis](https://github.com/darkroomengineering/lenis) | Lightweight smooth scrolling with a documented GSAP/ScrollTrigger integration | Adopt only if a future pinned narrative needs it; current native scroll is faster and sufficient |
| [greensock/GSAP](https://github.com/greensock/GSAP) | Mature sequencing and scroll choreography | Consider for a future real-footage shot sequence; current Motion dependency already covers product transitions |
| [pmndrs/react-three-fiber](https://github.com/pmndrs/react-three-fiber) | React renderer for Three.js with a large ecosystem | Do not add yet; WebGL is unjustified without a real 3D pack model and would increase cost/risk |
| [motiondivision/motion](https://github.com/motiondivision/motion) | Existing React animation system, strong layout and presence primitives | Keep; consistency beats adding a second animation runtime |

Popularity is not a design rationale. Add a library only when its unique capability serves the signature interaction and its loading, accessibility, and maintenance costs are understood.

## Human-attention model

1. Recognition: package silhouette, Arabic wordmark, and seven-color system create memory before copy is read.
2. Prediction: a numbered chapter rail tells the visitor there are seven worlds and makes exploration finite.
3. Agency: direct selection must interrupt autoplay; the interface respects intent.
4. Reward: each selection changes color, giant Arabic typography, product depth, sensory copy, and purchase signal together.
5. Trust: real package renders remain sharp; synthetic lifestyle claims are absent.
6. Action: price, taste notes, and add-to-bag stay inside the visual scene.

## Scoring rubric

Score each release 1–10:

- Brand distinctiveness 20%.
- Visual craft and typography 15%.
- Signature interaction 15%.
- Product/content realism 15%.
- Usability and accessibility 15%.
- Performance and media discipline 10%.
- Commerce clarity 10%.

No release is award-ready below 8/10 in usability, realism, or performance, regardless of average.
